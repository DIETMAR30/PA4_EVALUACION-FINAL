# Matriz de cumplimiento de la rúbrica PA4

| Criterio | Evidencia dentro del proyecto | Nivel buscado |
|---|---|---|
| Gameplay y entorno 3D | Bosque con ruinas 3D, CharacterController, cámara, colliders, salto, caída al vacío y objetivo de escape | Sobresaliente |
| Integración de sistemas | HUD, audio, partículas, recolección de runas, portal, victoria/derrota y pausa | Sobresaliente |
| IA y ambientación | Espiritu_Guardian con estados patrulla/alerta/persecución/aturdido + luz de luna, materiales, luciérnagas y niebla | Sobresaliente |
| Optimización y testing | ImpactPool, IA con intervalo de decisión y guía de pruebas | Sobresaliente |
| Código y sustentación | Scripts separados por responsabilidad, comentarios y README técnico | Sobresaliente |

> La rúbrica oficial prioriza funcionalidad, integración, experiencia de juego, organización del código y estabilidad por encima de la cantidad de assets. El proyecto mantiene un único nivel corto y completo para respetar ese enfoque.
